# Focus Screen

轻量 macOS 菜单栏工具：当前键盘焦点所在屏幕保持正常，其余屏幕覆盖固定 20% 黑色遮罩。支持多屏幕、跨桌面及原生全屏辅助窗口，不读取输入内容，不联网，不修改显示器硬件亮度。

## 构建与运行

要求 macOS 13+ 和 Xcode Command Line Tools（`xcode-select --install`），不依赖第三方库。

```sh
./scripts/test.sh
./scripts/build.sh
open dist/FocusScreen.app
```

点击菜单栏双屏图标 →「授权辅助功能…」，在系统设置中允许 FocusScreen。未授权前不会调暗任何屏幕。若系统列表没有出现应用，手动添加构建得到的 `dist/FocusScreen.app`。授权后自动生效；可从菜单暂停或退出。

本地构建使用 ad-hoc 签名，重新构建后若授权失效，在辅助功能列表移除旧项目并重新添加。应用不默认设置开机启动，也没有全局快捷键。

## 工作方式

通过 AXObserver 监听前台应用的焦点窗口变化，以及焦点窗口的移动、缩放、关闭、最小化和恢复。切换应用或窗口时重新绑定监听，密集 AX 通知合并为每 50 毫秒最多刷新一次。应用、Space、显示器变化及睡眠恢复会立即触发刷新，并在 150 毫秒后再次校验过渡状态。

通知注册完整且窗口可读取时，每 2 秒校验一次；通知注册失败或无法读取焦点窗口时，恢复每 250 毫秒轮询，并每 2 秒重试不完整的监听。成功注册不保证应用一定发送每次通知，遗漏的通知由校验补偿。暂停或单屏时停止 AX 监听和轮询；未授权时每 2 秒检查权限，授权后自动绑定。撤销权限最迟在下一次校验发现（定时器可能有调度延迟）。

按窗口与显示器的最大重叠面积决定焦点屏幕，正确转换左右、上下排列的坐标。不是根据鼠标位置判断，因此移动鼠标不会错误改变焦点。焦点屏幕不变时避免重复操作遮罩，系统切换事件除外。

遮罩使用不能激活的 NSPanel，鼠标穿透、不接收键盘焦点，配置跨 Space 和全屏辅助行为。单屏、未授权、应用不提供 AX 焦点窗口或查询失败时，撤掉全部遮罩。菜单显示当前状态。

## 验证清单

自动测试覆盖主屏、左侧/上方副屏坐标转换、跨屏最大交集、无交集及空输入，以及刷新合并、持续事件、系统事件立即刷新和延迟校验、取消及释放。真实 AX 通知与显示效果须在目标机器确认：

- 两块屏幕分别进入原生全屏，点击或使用 Command-Tab 切换后，仅非焦点屏幕调暗。
- 同一应用的不同全屏窗口切换，焦点提示仍正确。
- 同一应用内切换窗口、拖动或缩放窗口跨屏、关闭和最小化焦点窗口后，遮罩及时更新。
- 通知注册失败的应用仍能通过快速轮询更新；注册成功但漏发通知时，低频校验能修正状态。
- 在变暗的屏幕上点击、滚动，事件正常传递，应用获得焦点后恢复亮度。
- 鼠标停在另一屏但键盘焦点不变时，不应切换亮度。
- 切换 Space、睡眠恢复、拔插屏幕、调整屏幕上下/左右布局后恢复正确状态。
- 暂停、退出、撤销辅助功能权限后立即或在下一次检测时移除遮罩。
- Mission Control、系统弹窗及特殊应用全屏模式是否符合预期。

原生全屏叠加采用公开 AppKit API；不同系统及特殊全屏应用可能表现不同。镜像显示按单个逻辑屏幕处理。应用未暴露焦点窗口时保持所有屏幕明亮，不以鼠标位置猜测。
