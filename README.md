# Sidelit

**专注当前屏幕，调暗其他屏幕。**

轻量 macOS 菜单栏工具：正在操作的窗口所在屏幕保持原有亮度，其他屏幕覆盖可调黑色遮罩（默认 20%）。「当前屏幕」不跟随鼠标位置。支持多屏幕、跨桌面及原生全屏辅助窗口，不读取输入内容，不联网，不修改显示器硬件亮度。

## 构建与运行

要求 macOS 13+ 和 Xcode Command Line Tools（`xcode-select --install`），不依赖第三方库。

```sh
./scripts/test.sh
./scripts/build.sh
open dist/Sidelit.app
```

点击菜单栏双屏图标 →「授予辅助功能权限…」，在系统设置中允许 Sidelit。未授权前不会调暗任何屏幕。若系统列表没有出现应用，手动添加构建得到的 `dist/Sidelit.app`。授权后自动生效；取消勾选「调暗其他屏幕」即可暂停，也可从菜单退出。

本地构建使用 ad-hoc 签名，重新构建后若授权失效，在辅助功能列表移除旧项目并重新添加。应用没有全局快捷键。

从旧版 Focus Screen 更新时，请先退出旧应用，再启动 Sidelit。构建不会删除旧的 `FocusScreen.app`。新版本保留应用标识与设置键，不主动重置调暗程度和启用状态；授权与登录项可能需要重新配置，请从固定安装位置检查。

## 用户设置

- 「调暗其他屏幕」开关控制是否启用功能；单屏、未授权或程度为 0% 时，即使已勾选也不会产生可见调暗效果。
- 菜单中的「调暗程度」滑块可在 0%～100% 间按 1% 调节，拖动时立即更新其他屏幕。数值越大越暗：0% 不调暗，100% 全黑。鼠标始终穿透，完全变暗的屏幕仍可点击以切换回来；调整数值不会改变启用开关。
- 暂停、单屏或未授权时仍可调整并保存；调暗恢复后使用已保存的程度。
- `AppConfig` 统一管理调暗程度和启用状态，通过 `UserDefaults` 持久化，重启后恢复；内部轮询参数不属于用户配置。
- 「登录时自动启动」默认不注册，仅主动开启时调用系统。`LoginItemController` 通过 [SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp) 直接读写系统登录项，每次打开菜单重新读取，不在 `AppConfig` 中存放副本。系统已有注册时如实展示。
- 系统要求允许时显示「待允许」和混合勾选状态，可从「在系统设置中允许…」进入登录项设置，也可再次点击开关取消注册。注册或注销失败会显示原因，并重新读取实际状态。

建议将构建的应用放到固定位置（例如 `/Applications/Sidelit.app`），从该位置启动后再开启登录自启动；移动或删除已注册的应用可能影响下次登录启动。

菜单栏图标始终使用一明一暗的并排双屏图形，随系统深浅外观显示为单色。它不指示实际屏幕排列，也不随暂停或授权状态变化；打开菜单或悬停图标可查看当前屏幕与运行状态。

## 图标资源

应用图标采用深蓝灰与暖白的并排双屏构图。`Resources/AppIcon.icns` 已包含标准尺寸，正常构建直接打包。修改图标后可运行 `./scripts/generate-icons.sh`，从 `scripts/generate-icons.swift` 的矢量绘制源文件重新生成；中间 PNG 位于 `.build/Sidelit.iconset/`。菜单栏图标由 `Sources/StatusIcon.swift` 以原生模板图像绘制。

## 工作方式

通过 AXObserver 监听前台应用的焦点窗口变化，以及焦点窗口的移动、缩放、关闭、最小化和恢复。切换应用或窗口时重新绑定监听，密集 AX 通知合并为每 50 毫秒最多刷新一次。应用、Space、显示器变化及睡眠恢复会立即触发刷新，并在 150 毫秒后再次校验过渡状态。

通知注册完整且窗口可读取时，每 2 秒校验一次；通知注册失败或无法读取焦点窗口时，恢复每 250 毫秒轮询，并每 2 秒重试不完整的监听。成功注册不保证应用一定发送每次通知，遗漏的通知由校验补偿。暂停或单屏时停止 AX 监听和轮询；未授权时每 2 秒检查权限，授权后自动绑定。撤销权限最迟在下一次校验发现（定时器可能有调度延迟）。

按窗口与显示器的最大重叠面积决定当前屏幕，正确转换左右、上下排列的坐标。不是根据鼠标位置判断，因此移动鼠标不会错误改变当前屏幕。当前屏幕不变时避免重复操作遮罩，系统切换事件除外。

遮罩使用不能激活的 NSPanel，鼠标穿透、不接收键盘焦点，配置跨 Space 和全屏辅助行为。单屏、未授权、应用不提供 AX 焦点窗口或查询失败时，撤掉全部遮罩。菜单显示当前状态。

## 验证清单

自动测试覆盖屏幕坐标与归属、刷新调度、配置默认值与持久化及异常值、登录项状态与失败处理（模拟系统服务）、原生滑块动作及遮罩透明度更新。测试不修改真实登录项。真实 AX 通知、菜单拖动效果和登录启动须在目标机器确认：

- 两块屏幕分别进入原生全屏，点击或使用 Command-Tab 切换后，仅其他屏幕调暗。
- 同一应用的不同全屏窗口切换，当前屏幕提示仍正确。
- 同一应用内切换窗口、拖动或缩放窗口跨屏、关闭和最小化焦点窗口后，遮罩及时更新。
- 通知注册失败的应用仍能通过快速轮询更新；注册成功但漏发通知时，低频校验能修正状态。
- 在变暗的屏幕上点击、滚动，事件正常传递，应用获得焦点后该屏幕恢复原有亮度。
- 鼠标停在另一屏但键盘焦点不变时，不应切换亮度。
- 切换 Space、睡眠恢复、拔插屏幕、调整屏幕上下/左右布局后恢复正确状态。
- 暂停、退出、撤销辅助功能权限后立即或在下一次检测时移除遮罩。
- Mission Control、系统弹窗及特殊应用全屏模式是否符合预期。
- 菜单展开时拖动滑块保持菜单打开，调暗程度实时变化；0% 和 100% 端点正确，当前屏幕保持原有亮度。
- 暂停时调整滑块不显示遮罩，重新启用及重启应用后使用保存的设置。
- 登录项开启、关闭、系统设置中撤销允许、待允许及错误提示均反映真实状态；退出后重新登录可自动启动已注册的应用。
- Finder、辅助功能列表与登录项显示 Sidelit；应用图标清晰，菜单栏图标在深浅外观及不同缩放下清晰，状态变化不改变图形。

原生全屏叠加采用公开 AppKit API；不同系统及特殊全屏应用可能表现不同。镜像显示按单个逻辑屏幕处理。应用未暴露焦点窗口时，所有屏幕恢复原有亮度，不以鼠标位置猜测。
