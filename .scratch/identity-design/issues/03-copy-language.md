## Question

如何用同一套术语表达开关、调暗百分比、焦点屏幕、暂停、单屏、授权不足和无焦点窗口等状态？对照 Sources/main.swift、Sources/DimmingMenuView.swift 与 README.md，给出逐项旧文案与候选新文案，由用户确定。明确当前屏幕只是保持原样或恢复原样，「调亮」是否应避免，以及 0%／100% 如何解释。需要名称的地方在命名确定前使用占位符。

## Comments

### 整体候选（等待用户确认）

品牌名使用已确定的 Sidelit。舞台意象用于品牌表达，操作与状态使用直白的中文。

| 触点 | 旧文案 | 推荐文案 |
| --- | --- | --- |
| 一句话介绍 | README 开头的技术性概述 | 专注当前屏幕，调暗其他屏幕。 |
| 勾选式功能开关 | 启用屏幕调暗 | 调暗其他屏幕 |
| 滑块标题 | 调暗程度 | 调暗程度（保留） |
| 滑块辅助功能名称 | 调暗程度，百分比 | 其他屏幕的调暗程度，百分比 |
| 初始化 | 正在检测焦点… | 正在识别当前屏幕… |
| 正常状态 | 焦点：<屏幕名称> | 当前屏幕：<屏幕名称> |
| 暂停状态 | 已暂停 | 已暂停调暗 |
| 单屏状态 | 单屏幕，无需调暗 | 仅连接一个屏幕，无需调暗 |
| 权限不足 | 需要辅助功能授权 | 需要辅助功能权限 |
| 权限入口 | 授权辅助功能… | 授予辅助功能权限… |
| 无焦点窗口或查询失败 | 未识别到焦点窗口 | 无法确定当前屏幕 |
| 退出菜单 | 退出 Focus Screen | 退出 Sidelit |

补充说明与术语约束：

- 「当前屏幕」指正在操作的窗口所在屏幕，不跟随鼠标位置；这句话放在说明文档中，不重复塞入状态行。
- 滑块数值越大，其他屏幕越暗。0% 为「不调暗」，100% 为「完全变暗」。详细说明注明 100% 时其他屏幕内容被黑色遮罩完全覆盖，仍可点击以切换回来。
- 百分比标签继续显示 n%，端点含义放在说明或帮助文字中，无须增加新控件。
- 减小数值描述为「减弱调暗」，增大数值描述为「加深调暗」；当前界面没有独立增减按钮，不为这些词增加新操作。
- 撤去调暗效果描述为「恢复原有亮度」。不把切换当前屏幕或降低遮罩强度称为主动「调亮」。
- 开关使用固定标题和勾选状态，不混用「开启专注」「开灯」「落幕」等新概念。开关开启表示功能已启用，不承诺当前一定有屏幕变暗（例如单屏、0% 或未授权）。
- 暂停、单屏、未授权时仍允许调整并保存程度；说明文字为「调暗恢复后使用已保存的程度」。
- 状态 tooltip 与菜单状态使用同一文案；无法确定当前屏幕时恢复所有屏幕原有亮度，不宣称应用发生故障。
- 登录项相关文案保留当前结构；其中品牌名替换为 Sidelit。系统触点与完整提示由后续呈现规范票统一复核。
