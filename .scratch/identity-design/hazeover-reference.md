# HazeOver：命名、图标与调暗表达参考

研究日期：2026-09-18。对应决策票「HazeOver 如何表达专注、调暗与视觉识别」。仅记录参考事实与建议，不替用户确定名称或正式设计。

## 可核验的观察

| 层级 | 官方表达与含义 | 一手来源 |
| --- | --- | --- |
| 品牌 | 中英文均保留 HazeOver；英文定位用 Distraction Dimmer，中文译作「分心调光器」。品牌名和功能说明分开。 | [英文首页](https://hazeover.com/)、[中文首页](https://hazeover.com/zh_cn/) |
| 收益与机制 | 先讲减少干扰、专注眼前任务，再解释通过背景变暗形成对比，并非直接提高前台亮度。 | [英文首页](https://hazeover.com/)、[中文首页](https://hazeover.com/zh_cn/) |
| 术语 | 英文围绕 dimming、intensity；中文出现调暗、调光强度、阴影等不同译法。可借鉴语义层级，不必照搬术语混用。 | [英文首页](https://hazeover.com/)、[中文首页](https://hazeover.com/zh_cn/) |

## 本项目适用边界

依据本地图给定的实现事实：当前焦点窗口所在屏幕保持原样，其他整块屏幕叠加黑色遮罩；0% 为无遮罩，100% 为全黑。同一当前屏幕上的背景窗口不会像 HazeOver 的窗口模式那样单独变暗。

可以借鉴“先讲专注收益，再讲调暗机制”，但应明确对象是其他屏幕，不能承诺自动突出单个窗口，也不能把遮罩程度说成硬件亮度。

## 后续讨论建议（尚未定案）

| 触点 | 候选表达 | 理由 |
| --- | --- | --- |
| 产品介绍 | 专注当前屏幕，调暗其他屏幕 | 同时说明价值和作用对象。 |
| 功能开关 | 调暗其他屏幕 | 直接描述行为。 |
| 滑杆 | 调暗程度 | 数值越大越暗，与遮罩比例同向。 |
| 端点 | 0%：不调暗；100%：全黑 | 避免误解为亮度百分比。 |
| 增减操作 | 加深调暗／减弱调暗 | 不暗示提升硬件亮度；措辞需结合控件比较。 |
| 关闭功能 | 停止调暗 | 若操作仅影响单屏，应明确屏幕对象。 |

用户认可的双屏明暗方向适合表达本项目的作用范围：两块屏幕轮廓配合填充或明暗对比；单色菜单栏版本应通过轮廓、填充保留区别，不能只依赖颜色。这是设计推论，并非复刻 HazeOver 图标的要求。

英文品牌名可与中文功能说明分离。保留 Focus Screen 并探索少量新名称，最终与双屏图标一起评议；本研究未调查候选名称占用，不形成商标可用性结论。

## 后续决策与未知项

- 英文名及其对多屏场景的提示程度。
- 图标小尺寸辨识度，以及启用、暂停状态的表达。
- 各控件控制全局程度、单屏程度还是开关，决定具体动词。
- 中文覆盖范围及系统各触点的最终名称。
